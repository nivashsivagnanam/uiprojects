# uiprojects
 These project demonstrate authendication flow, protected routes CRUD operations ,Localstorage 
 # FEATURES
   Dummy Authendication(Login/Logout)
   Protected Routes using reactRouter
   uses LocalStorage 
   Tost notification
   Build with Vite for fast development.
# teck Stack:
  react ---UI Library
  vite ---- Fast Development building tool
  React Router DOM ---Router and Navigation
  React Toastify ---Notification
  CSS --- styling
# reactHooks used:
   useState ---add a state variable to your component.
   useEffect ---connect to the external system (LocalStorage in browser)
   useNavigation --- used to navigate 
# SetUp Instruction :
 create a folder (uiprojects)
 run the Terminal
   RUN:npm create vite@latest 
   cd frontend
   npm install
   npm install react react-dom react-router-dom  react-tostify in your terminal 
   npm run dev
